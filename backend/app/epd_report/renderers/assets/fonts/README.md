# EPD report fonts

`EPDReportSans-*.ttf` are glyph subsets of **Source Sans 3** (Adobe, SIL Open Font License 1.1 — see `LICENSE.md`),
reduced to Latin, Greek, punctuation, super/subscripts and common symbols so they can be embedded in every report.
Because subsetting is a modification under the OFL and "Source" is a Reserved Font Name, the subset family is
renamed to "EPD Report Sans".
